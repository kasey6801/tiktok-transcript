Saving to disk

Transcripts always stay in this browser. Save them to disk as well and the history survives removing the extension.

Saving to:

Chrome only lets extensions write inside the browser's download folder, so the part above the subfolder is whatever Chrome is set to. Change it at chrome://settings/downloads to put transcripts anywhere you like.
